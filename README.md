# Everwood USA

Website for [Everwood USA](https://everwood-usa.com), a locally owned Miami Beach company in partnership with Desafío Ambiente / Everwood Chile.

The site is static HTML, CSS, and JavaScript, with no build step. GitHub Pages serves this repository from the root. The custom domain `everwood-usa.com` is set in `CNAME`.

## Folder structure

- `index.html` — home page
- `pages/` — About, Products, Projects, Partnerships, Impact, Shop, Full Circle, Investors, Contact, and Credits
- `assets/css/` — stylesheets
- `assets/js/` — site JavaScript
- `assets/img/` — photographs, product images, and logos
- `screenshots/` — page captures
- `CNAME` — GitHub Pages custom domain

## Local preview

From the repository root:

```bash
python3 -m http.server
```

Then open http://localhost:8000.
